For compression only, Mathula may use natural isiZulu contextual ellipsis, deictic reference,
and compact echo/confirmation wording when the current source repeats a proposition already
explicit in the immediately preceding locked dialogue. Unique current facts remain mandatory.
The following source block is interpretation-only and can never justify an omission.

Each compress item also carries a deterministic target syllable reduction derived from the
measured Azure duration deficit and the current phrase's measured syllable realization rate.
